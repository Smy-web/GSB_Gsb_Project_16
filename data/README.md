# data/ —— 手工样例夹具

两个文件都很小（18 行订单 + 12 行退款），**每一行都是故意设计来踩中某条历史怪癖的**。
口径权威描述在 `../legacy/report_legacy.py` 文件头的 docstring 里，这里只说
「哪一行在考什么」。

跑法（在仓库根目录）：

```bash
python3 legacy/report_legacy.py --orders data/orders.csv --refunds data/refunds.csv --out /tmp/legacy
python3 -m reportbuild          --orders data/orders.csv --refunds data/refunds.csv --out /tmp/new
diff -r /tmp/legacy /tmp/new && echo "逐字节一致"
```

## orders.csv 逐行对照

| 行 | 在考什么 |
|---|---|
| `O00000001` | 最普通的正常行 |
| `O00000002` | `2.675` → **Q1** float 舍入痕迹（落盘 `2.67`，不是财务口径的 `2.68`） |
| `O00000003` | ts 用**空格**分隔而不是 `T`，`0.145` 再考一次 Q1 |
| `O00000004` | `88.885`，Q1 |
| `O00000005` | `region` 为**空串** → **Q5**：单独成一行，字典序排在所有非空 region 前面 |
| `O00000006` | `2026-08-31T23:59:59`，月末最后一秒，归 8 月 |
| `O00000007` | ts 带 `+08:00` 偏移且压在月初零点 → **Q6**：按字面归 `2026-09`，换算成 UTC 其实还在 8 月 |
| `O00000008` | `ts = not-a-date` → 整行跳过，`skipped_rows += 1` |
| `O00000009` | `ts` 为空 → 同上跳过 |
| `O00000010` | `ts = 2026-13-45 99:99:99`（月日时分秒全越界）→ 同上跳过 |
| `O00000011` | `amount` 为**空串** → **Q4**：按 `0.0` 计，**不跳行** |
| `O00000012` | `amount = N/A` → 同 Q4，按 `0.0` 计，不跳行 |
| `O00000013` ×2 | **同一个 order_id 跨月出现两次** → `duplicate_order_ids = 1`，且它的全部退款都归到**首次出现**的 `华北/2026-08`（**Q3**） |
| `O00000014` | 订单侧 `amount = -20.00` → **Q8**：原样进 gross，**不**像退款那样裁成 0 |
| `O00000015` | `0.005`，Q1 |
| `O00000016` | `7.135`，Q1；region `海外` 在字典序里排最后 |
| `O00000017` | `2026-09-30T23:59:59`，月末边界 |

数一下：18 行数据，其中 3 行 ts 坏 → `skipped_rows = 3`，活行 15 行，
分成 **7 个** `(region, month)` 组，`duplicate_order_ids = 1`。

## refunds.csv 逐行对照

| 行 | 在考什么 |
|---|---|
| `RF0000001` | 普通退款，归 `华东/2026-09` |
| `RF0000002` | `2.675`，退款侧的 Q1 |
| `RF0000003` | **负退款** `-50.00` → **Q2**：按 `0.0` 计，不冲减；归属走 **Q3** 到 `华北/2026-08` |
| `RF0000004` | 同一个 `O00000013` 的第二笔退款，**也**归到 `华北/2026-08`（Q3），`华北/2026-09` 一分钱退款都拿不到 |
| `RF0000005` | 指向 `O00000008`，而那行是 ts 坏行 → **口径 5**：算 `orphan_refunds` |
| `RF0000006` | 指向根本不存在的 `O99999999` → `orphan_refunds` |
| `RF0000007` | 归到 region 为**空串**的那组（Q5） |
| `RF0000008` | 退款金额为**空串** → 按 `0.0` |
| `RF0000009` | 退款金额 `N/A` → 按 `0.0` |
| `RF0000010` | `-0.01` 负退款 → Q2，按 `0.0` |
| `RF0000011` | 指向 `O00000011`（那行 amount 是空串但**没被跳过**）→ 能正常归属，不算孤儿 |
| `RF0000012` | `88.885`，Q1 |

数一下：12 行退款，`orphan_refunds = 2`。

## 大数据夹具

`data/` 里只有小样例。**20 万规模的数据不入库**，用 `tools/gen_data.py`
现生成（固定种子，可复现）：

```bash
python3 tools/gen_data.py --out /tmp/big --orders 200000 --refunds 20000 --seed 20260901
```

各种极端场景（全脏数据 / 全退款孤儿 / 单 region / 空退款表 / 大量重复 order_id /
带时区偏移）见 `python3 tools/gen_data.py --help` 里的 `--profile`。
